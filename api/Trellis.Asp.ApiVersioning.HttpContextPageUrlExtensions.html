Remarks

Shares destination-version mapping with WithVersionedRoute<TDomain>(HttpResponseOptionsBuilder<TDomain>) for paginated Link / next URLs: query/header versioning round-trips api-version automatically; version-neutral endpoints skip automatic api-version injection; endpoints with no Asp.Versioning.ApiVersionMetadata attached (hosts that never called AddApiVersioning(...)) likewise skip injection so PageUrl composes cleanly in unversioned and mixed-versioned hosts. For URL-segment versioning, the per-request overload skips query injection and lets ambient route data fill the path segment; the explicit-version overload throws instead, because silently dropping the pin would let LinkGenerator emit a URL with the wrong path-segment version.

Builds absolute URLs via LinkGenerator.GetUriByRouteValues(HttpContext, ...) so the emitted next-page URL preserves Scheme, Host, and PathBase from the current request.

The returned Func<T1, T2, TResult> captures the current HttpContext and is therefore request-scoped: invoke it during the same request that produced it, before the response completes. Don't hand it to a background task.

Returns a (Cursor, int) -> string builder pinned to a specific Asp.Versioning.ApiVersion regardless of what the client requested. Use for cross-version list-page URLs (e.g. a deprecated endpoint redirecting paginated traffic to its successor).

public static Func<Cursor, int, string> PageUrl(this HttpContext httpContext, string routeName, ApiVersion version, Func<Cursor, int, RouteValueDictionary> routeValues)

Parameters

The current request context.

routeName string

The name of the target route.

version ApiVersion

The version to inject on versioned targets, provided it is mapped to the destination.

routeValues Func<Cursor, int, RouteValueDictionary>

A callback that maps (cursor, appliedLimit) to the route-value dictionary for the next-page URL. The helper clones this dictionary before injecting api-version.

Returns

Func<Cursor, int, string>

A request-scoped URL builder. Must be invoked during the same request.

Remarks

The explicit version is still silently suppressed on version-neutral endpoints — emitting a query api-version on a neutral endpoint would mislead clients into resending the URL with a parameter the target rejects.

Unversioned-host behaviour: when the target endpoint has no Asp.Versioning.ApiVersionMetadata — the host never called AddApiVersioning(), or the endpoint sits outside its surface — the pin is silently suppressed and a clean URL is emitted (the pinned version has no target declaration set to validate against, and emitting it as a query parameter would be a stale URL artefact). This lets PageUrl compose in unversioned hosts.

Exceptions

ArgumentNullException

httpContext, version, or routeValues is null.

ArgumentException

routeName is null, empty, or whitespace.

InvalidOperationException

Thrown by the returned builder when (a) the target route name resolves to no registered endpoint, (b) the target route is URL-segment-versioned (route template contains :apiVersion) — the pin cannot be honoured as a query parameter because the version belongs in the path segment, and silently dropping the pin would let LinkGenerator fill the segment from ambient route data and produce a URL with the wrong version; switch to the per-request overload PageUrl(HttpContext, string, Func<Cursor, int, RouteValueDictionary>), (c) the target endpoint has Asp.Versioning.ApiVersionMetadata but does not declare version among its implicit or explicit declared versions — emitting the URL would produce a link the target rejects (e.g. 400 from the versioning middleware) when the client follows it, or (d) LinkGenerator returns null.

PageUrl(HttpContext, string, Func<Cursor, int, RouteValueDictionary>)

Returns a (Cursor, int) -> string builder suitable for the nextUrlBuilder parameter of Trellis.Asp's paged ToHttpResponse overloads. Resolves the api-version route value from the request (per-request mode).

public static Func<Cursor, int, string> PageUrl(this HttpContext httpContext, string routeName, Func<Cursor, int, RouteValueDictionary> routeValues)

Parameters

httpContext HttpContext

The current request context.

routeName string

The name of the target route (typically the current paginated endpoint's route name).

routeValues Func<Cursor, int, RouteValueDictionary>

A callback that maps (cursor, appliedLimit) to the route-value dictionary for the next-page URL. The helper clones this dictionary before injecting api-version, so you may return a shared instance from the callback without it being mutated.

Returns

Func<Cursor, int, string>

A request-scoped URL builder. Must be invoked during the same request.

Remarks

Cross-route caveat: when routeName differs from the current endpoint's route name, the skip rules and declared-version fallback are evaluated against the TARGET endpoint, not the current one. The per-request RequestedApiVersion (when the client supplied one) is echoed only when the target endpoint declares it; otherwise the resolver falls through to the target's single declared version or to DefaultApiVersion. This prevents emitting a URL the target would reject when the client follows it.

Unversioned-host behaviour: when the target endpoint has no Asp.Versioning.ApiVersionMetadata — the host never called AddApiVersioning(), or the endpoint sits outside its surface — the helper skips api-version injection silently and emits a clean URL. This lets PageUrl compose in unversioned hosts and in mixed-versioned hosts where individual paginated endpoints are not part of the versioning surface.

Exceptions

ArgumentNullException

httpContext or routeValues is null.

ArgumentException

routeName is null, empty, or whitespace.

InvalidOperationException

Thrown by the returned builder when (a) the target route name resolves to no registered endpoint, (b) a multi-version endpoint has no client-requested version AND no DefaultApiVersion is configured, or (c) LinkGenerator returns null (route + ambient values produced no match).
