ClaimsActorProvider for requests authenticated by Azure App Service / Container Apps built-in authentication ("Easy Auth"). Actor resolution is inherited verbatim from ClaimsActorProvider — it maps HttpContext.User claims (populated by EasyAuthAuthenticationHandler) to the actor id and permissions using ClaimsActorOptions.

Remarks

The only behavioral difference from ClaimsActorProvider is VaryByHeaders: an Easy Auth actor is derived from the platform principal headers, not Authorization. Reusing the base provider unchanged would emit Vary: Authorization and let an intermediate cache serve one actor's response to another when an endpoint calls VaryForActor().
