Remarks

Actor has no role concept — permissions must be pre-flattened from all sources (JWT roles, database groups) before the actor is constructed so every check stays O(1). This helper performs that flattening from a map the application owns, replacing the hand-rolled roles.SelectMany(r => map[r]) shape that throws on an unmapped role.

Roles absent from the map are skipped rather than throwing, so a token carrying a role the service does not recognize yields the recognized permissions instead of a 500. The result is an ordinal, deduplicated set matching Actor's ordinal permission comparison.

The map is captured by reference; supply a stable, effectively-immutable map (it is read concurrently, once per request).

ExpandRoles(IEnumerable<string>, IReadOnlyDictionary<string, IReadOnlyCollection<string>>)

Expands the given role names into a flattened, ordinal-deduplicated permission set using rolePermissions. Roles not present in the map are skipped; null or whitespace role names and permission values are ignored.

public static IReadOnlySet<string> ExpandRoles(IEnumerable<string> roles, IReadOnlyDictionary<string, IReadOnlyCollection<string>> rolePermissions)

roles IEnumerable<string>

The role names to expand (for example, the values of a token's role claims).

The application-supplied map from role name to the permissions that role grants. Role lookups use the map's own key comparer, so a case-insensitive map matches case-variant role names.

public static Func<IEnumerable<Claim>, IReadOnlySet<string>> ForRoleClaims(IReadOnlyDictionary<string, IReadOnlyCollection<string>> rolePermissions, string? roleClaimType = null, bool keepRolesAsPermissions = false)

Parameters

rolePermissions IReadOnlyDictionary<string, IReadOnlyCollection<string>>

The application-supplied role→permissions map (see ExpandRoles(IEnumerable<string>, IReadOnlyDictionary<string, IReadOnlyCollection<string>>)).

roleClaimType string

The claim type carrying role names. When null (the default), both the short "roles" claim and its mapped Role URN are matched (case-insensitively), mirroring the EntraActorOptions default and tolerating JwtBearerOptions.MapInboundClaims either way. Pass an explicit type to match only that.

keepRolesAsPermissions bool

When true, each role name that is present in the map is also added to the result (for systems where a recognized role name doubles as a coarse permission). Roles absent from the map are skipped entirely — their name is never added. Defaults to false.

Returns

Func<IEnumerable<Claim>, IReadOnlySet<string>>

A delegate that maps a claim sequence to the granted permissions.

Exceptions

ArgumentNullException

rolePermissions is null.

ArgumentException

roleClaimType is non-null but empty or whitespace.
