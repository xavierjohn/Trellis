Namespace Trellis.Asp.Authorization

Classes

CachingActorProvider

Decorating IActorProvider that caches the result of the inner provider so that multiple calls within the same scope return the same actor without repeating expensive operations (e.g., database lookups).

ClaimsActorOptions

Configuration options for ClaimsActorProvider. Controls which claims are used for actor identity and permissions.

ClaimsActorProvider

IActorProvider implementation that hydrates an Actor from the current User using standard JWT/OIDC claims. Works with any identity provider (Auth0, Keycloak, Okta, Entra, etc.).

DevelopmentActorOptions

Configuration options for DevelopmentActorProvider. Controls the fallback actor used when no X-Test-Actor header is present, and error handling for malformed headers.

DevelopmentActorProvider

IActorProvider implementation for development and testing that reads actor identity from the X-Test-Actor HTTP header.

EasyAuthAuthenticationExtensions

Extension methods for registering the Azure App Service / Container Apps built-in authentication ("Easy Auth") scheme.

EasyAuthAuthenticationHandler

Authentication handler that turns Azure App Service / Container Apps built-in authentication ("Easy Auth") principal headers into an authenticated ClaimsPrincipal on HttpContext.User. Once the principal is on the context, the standard Trellis actor providers (ClaimsActorProvider / EasyAuthClaimsActorProvider) map its claims to an Actor — no bespoke header parsing in the actor layer.

EasyAuthAuthenticationOptions

Options for EasyAuthAuthenticationHandler. The Easy Auth principal header names are fixed by the Azure platform contract (see EasyAuthDefaults) and are not configurable; this type carries only the standard AuthenticationSchemeOptions surface (events, forwarding, etc.).

EasyAuthClaimsActorProvider

ClaimsActorProvider for requests authenticated by Azure App Service / Container Apps built-in authentication ("Easy Auth"). Actor resolution is inherited verbatim from ClaimsActorProvider — it maps HttpContext.User claims (populated by EasyAuthAuthenticationHandler) to the actor id and permissions using ClaimsActorOptions.

EasyAuthDefaults

Default scheme name and request-header names for Azure App Service / Azure Container Apps built-in authentication ("Easy Auth"), consumed by EasyAuthAuthenticationHandler and EasyAuthClaimsActorProvider.

EntraActorOptions

Configuration options for EntraActorProvider. Controls how Azure Entra ID v2.0 JWT claims are mapped to Actor properties.

EntraActorProvider

IActorProvider implementation that hydrates an Actor from the current User using Azure Entra ID v2.0 JWT claims. Extends ClaimsActorProvider with Entra-specific claim mapping for permissions, forbidden permissions, and ABAC attributes.

NestedJsonPathClaimsActorOptions

Configuration options for NestedJsonPathClaimsActorProvider. Maps an identity provider's nested-JSON claim shape (Auth0 app_metadata.roles, Azure B2C extension_*, Okta nested claims) onto Id and Permissions via a dotted JSON path.

NestedJsonPathClaimsActorProvider

ClaimsActorProvider derivation that maps an identity provider's nested-JSON claim shape (Auth0 app_metadata.roles, Azure B2C extension_*, some Okta token shapes) onto Id and Permissions via a dotted JSON path. Falls back to the inherited flat-claim resolution when the configured paths are empty.

RolePermissionProjection

Projects coarse role names into the granular permission set an Actor carries, using an application-supplied role→permissions map.

ServiceCollectionExtensions

Extension methods for registering actor providers in ASP.NET Core DI.

IProvideActorVaryHeaders

Optional capability that an IActorProvider implementation can expose so callers of VaryForActor() can emit the correct Vary headers for cache partitioning by actor.
