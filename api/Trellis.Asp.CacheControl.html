Remarks

Every helper returns a fresh CacheControlHeaderValue on each call. CacheControlHeaderValue is mutable, so mutating an instance returned by one of these helpers does not leak into a later call.

Use directly: opts.WithCacheControl(CacheControl.NoStore()), or pick the BCL type directly when you need a directive that isn't represented as a property on CacheControlHeaderValue.

Immutable(TimeSpan)

Cache-Control: public, max-age={seconds}, immutable — the response will not change for its freshness lifetime, so clients should not revalidate. The immutable directive (RFC 8246) is appended via the Extensions collection because the BCL type has no dedicated property for it.

public static CacheControlHeaderValue NoStore()

Returns

CacheControlHeaderValue

Remarks

Use for responses that may contain personal data, secrets, or per-user state. Applies to both success and failure responses through WithCacheControl(CacheControlHeaderValue) — a 404 from a sensitive endpoint is no less sensitive than the 200.
