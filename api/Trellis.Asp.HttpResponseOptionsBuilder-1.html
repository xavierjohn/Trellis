WithLink(string, string)

Adds an RFC 8288 Link relation to the response.

public HttpResponseOptionsBuilder<TDomain> WithLink(string rel, string href)

Parameters

rel string

A registered relation token (for example describedby) or an absolute URI.

href string

The link target.

Returns

HttpResponseOptionsBuilder<TDomain>

Remarks

Use describedby to point at a schema describing this resource, or service-desc (RFC 8631) to point at an API description document such as an OpenAPI file. Both are IANA-registered. schema is not a registered relation type, and RFC 8288 §3.3 admits only a registered token or an absolute URI — so a bare rel="schema" is non-conformant and generic clients ignore it. Register your own extension relation as an absolute URI if neither registered relation fits.

Call this more than once to advertise several relations. Configured relations are additive to the next/prev links emitted for a paginated response.

Exceptions

ArgumentNullException

Thrown when rel or href is null.

ArgumentException

Thrown when rel is neither a valid relation token nor an absolute URI, or when href is blank.

WithLocation(string, Func<TDomain, RouteValueDictionary>)

Adds a Location header to the response (status code unchanged — typically 200 OK), generated as a relative path via LinkGenerator.GetPathByName at execute time. RFC 9110 §10.2.2 permits Location on any 2xx response that identifies a related resource; use this on state-transition endpoints that mutate an existing resource and want to point clients at the canonical URL (e.g. POST /orders/{id}/return returning 200 OK).

public HttpResponseOptionsBuilder<TDomain> WithLocation(string routeName, Func<TDomain, RouteValueDictionary> routeValues)

Parameters

routeName string

The route name.

routeValues Func<TDomain, RouteValueDictionary>

A function that returns a RouteValueDictionary for the resource being located.

Returns

HttpResponseOptionsBuilder<TDomain>

Remarks

Unlike CreatedAtRoute(string, Func<TDomain, RouteValueDictionary>), this does not set the status code to 201 Created — the response ships with its natural 2xx status code. This applies on the Result<T> execution path (ToHttpResponse). On Result<WriteOutcome<T>>, the builder still applies for other options, but WithLocation itself has no effect on the outcome's Location handling — that path reads WriteOutcome.Created.Location, WriteOutcome.Accepted.MonitorUri, and WriteOutcome.AcceptedNoContent.MonitorUri directly. On the Result<T> path, to round-trip the requested api-version through the generated Location, chain WithVersionedRoute() from Trellis.Asp.ApiVersioning; on the Result<WriteOutcome<T>> path, the version must instead be present in the URL the outcome itself carries.

WithRouteValueResolver(string, Func<HttpContext, string?>)

Registers a per-request resolver that injects (or overrides) a single route-value entry at Location-header generation time. Invoked AFTER the CreatedAtRoute(string, Func<TDomain, RouteValueDictionary>) / CreatedAtAction(string, Func<TDomain, RouteValueDictionary>, string?) route-values selector runs; if the resolver returns non-null, the value is set under key in the resulting RouteValueDictionary (overriding any existing entry under the same key). If the resolver returns null, the entry is left untouched.

public HttpResponseOptionsBuilder<TDomain> WithRouteValueResolver(string key, Func<HttpContext, string?> resolver)

Parameters

key string

The route-value key to inject.

The per-request resolver. Receives the active HttpContext; returns the value to inject, or null to skip.

Returns

HttpResponseOptionsBuilder<TDomain>

Remarks

Designed for cross-cutting per-request concerns such as API versioning (a Location header that round-trips the requested version), tenant id, or culture. Multiple resolvers can be registered with distinct keys; calling this method again with the same key replaces the previous resolver. Useful with CreatedAtRoute(string, Func<TDomain, RouteValueDictionary>), CreatedAtAction(string, Func<TDomain, RouteValueDictionary>, string?) and WithLocation(string, Func<TDomain, RouteValueDictionary>); ignored by literal/selector Location modes.
