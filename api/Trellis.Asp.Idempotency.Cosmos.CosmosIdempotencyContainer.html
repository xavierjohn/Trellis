Remarks

Per-item ttl is ignored unless the container enables TTL, so a container created without DefaultTimeToLive would accumulate idempotency entries forever. This helper sets it to -1, which enables TTL but expires nothing by default, leaving each item's own ttl in control.

Partitioning by scope keeps every operation for one key inside a single logical partition, which is what makes the store's create-or-conditionally-replace protocol atomic. Because scope is derived from the actor or tenant, keys spread evenly across partitions in multi-tenant hosts. A host that resolves every request to one shared scope — for example by mounting the middleware before authentication, so everything falls back to anonymous — would concentrate all traffic on one partition and hit its throughput limit.
