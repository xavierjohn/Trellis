Remarks

All defaults match the published Trellis contract; changing them is a breaking change for consumers. Override individual values via AddTrellisIdempotency(o => ...).

Properties

AdditionalFingerprintHeaders

Names of additional request headers that contribute to the request fingerprint beyond method, path, canonical query string, body bytes, Content-Type, and Content-Encoding. Add headers here when their value materially changes the response representation (for example Accept, Accept-Language, Prefer).

public ICollection<string> AdditionalFingerprintHeaders { get; }

Property Value

ICollection<string>

Remarks

Header values are normalised before hashing: leading and trailing whitespace are trimmed, and multiple values are concatenated with U+001F between entries.

HeaderName

Name of the request header carrying the client-supplied idempotency key. Defaults to "Idempotency-Key" per IETF draft draft-ietf-httpapi-idempotency-key-header.

public string HeaderName { get; set; }

Property Value

string

IncludeSetCookieInSnapshot

When true, Set-Cookie response headers are included verbatim in captured snapshots. When false (default) they are stripped from snapshots so a replay does not re-issue session or authentication cookies that have since been rotated.

public bool IncludeSetCookieInSnapshot { get; set; }

Property Value

bool

MaxKeyLength

Maximum length, in characters, of the idempotency key once unwrapped from any RFC 8941 sf-string quoting. Requests with a key longer than this fail with a 400 ProblemDetails before the handler runs. Defaults to 200, matching common provider conventions.

public int MaxKeyLength { get; set; }

Property Value

int

MaxRequestBodyBytes

Maximum request body size, in bytes, that the middleware will buffer in order to compute a fingerprint. Larger bodies fail with 413 Payload Too Large before the handler runs. Defaults to 1 MiB.

public long MaxRequestBodyBytes { get; set; }

Property Value

long

MaxResponseBodyBytes

Maximum response body size, in bytes, that the middleware will capture for replay. On overflow the original response is still emitted to the client, but the snapshot is abandoned and a subsequent retry will re-execute the handler. Defaults to 1 MiB.

public long MaxResponseBodyBytes { get; set; }

Property Value

long

Methods

HTTP methods on which an [Idempotent]-marked endpoint is treated as idempotent. Defaults to POST and PATCH. PUT and DELETE are already idempotent per RFC 9110 and are not added by default.

public ICollection<string> Methods { get; }

Property Value

ICollection<string>

MismatchStatusCode

HTTP status code to return when a key already in use in the same scope is reused with a different request fingerprint (method, path, query, fingerprinted headers, or body bytes). Defaults to 422 (Unprocessable Entity), matching the convention used by Stripe and Adyen.

public int MismatchStatusCode { get; set; }

int

ReplayHeaderName

Name of the response header added to replayed responses so clients can detect that the body originated from a cached snapshot rather than a fresh handler invocation. Defaults to "Idempotent-Replayed".

public string ReplayHeaderName { get; set; }

RequireKeyOnOptedInEndpoints

When true, opted-in endpoints reject requests that omit the idempotency header with a 400 ProblemDetails. When false, missing-key requests pass through to the handler with no idempotency processing. Defaults to true.

public bool RequireKeyOnOptedInEndpoints { get; set; }

Property Value

bool

ReservationTimeout

Maximum time a single reservation may remain open before another request with the same key is allowed to take over. Bounds the window during which a hung or crashed handler could prevent a retry from making progress. Defaults to 30 seconds.

public TimeSpan ReservationTimeout { get; set; }

Property Value

TimeSpan

Ttl

How long a completed snapshot stays available for replay. After the TTL elapses the stored entry is treated as not present, so a retry with the same key is processed as a fresh request. Defaults to 24 hours.

public TimeSpan Ttl { get; set; }
