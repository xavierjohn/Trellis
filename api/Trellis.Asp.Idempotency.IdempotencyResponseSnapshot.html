Remarks

Record equality on this type is the C# record default: scalar fields (StatusCode, Fingerprint) compare by value, but Headers and Body compare by reference because Default for IReadOnlyDictionary<TKey, TValue> and byte[] falls back to ReferenceEquals(object, object). Snapshot equality is not used by the middleware or the in-memory store for lookups (those are keyed by (scope, key)); consumers that need to compare two snapshots structurally must do so explicitly.

Parameters

StatusCode int

The HTTP status code of the original response.

Headers IReadOnlyDictionary<string, string[]>

Response headers as written by the handler, after IdempotencyOptions filtering (for example Set-Cookie stripped when IncludeSetCookieInSnapshot is false). Header names are matched case-insensitively.

Body byte[]

The raw response body bytes captured from the handler.

Fingerprint string

The request fingerprint that produced this snapshot. Stored alongside the response so a replay can reject a key reused in the same scope with a different request fingerprint (method, path, query, fingerprinted headers, or body bytes).
