Model binder for Maybe<T> parameters where T is an STJ-native primitive in the closed allowed list defined by SupportedPrimitives. Binds optional route, query, form, and header parameters into Maybe<T>.

Remarks

  • Parameter absent or empty → Maybe<T>.None (success, value not provided).
  • Parameter present and parsable as T → Maybe.From(parsedValue).
  • Parameter present but unparsable → model-state error; result is Failed().

Closes the binder-side parity gap with MaybeScalarValueJsonConverterFactory: route / query / header parameters typed Maybe<long> / Maybe<string> / etc. now bind directly without a wire-shape DTO + adapter at the seam. The allowed list lives on MaybePrimitives (non-generic) so the FrozenSet<T> is allocated once for the entire framework rather than once per closed generic.
