Remarks

Registered as a singleton via TryAddSingleton by AddTrellisAsp (which leaves the registry empty by default), and pre-populated with the supplied overrides by AddResourceCollectionName and AddResourceCollectionNames. Resource types without an override fall back to the naive plural; calling AddTrellisAsp alone means every type uses the naive plural. When none of those helpers are called, the registry is absent from DI and Trellis.Asp.ResponseFailureWriter falls back to an internal empty registry.

Override lookups are case-insensitive (OrdinalIgnoreCase) so a domain that emits both ResourceRef.For<Person>() and ResourceRef.For("person", id) sees the same plural.

Methods

Resolve(string)

Resolves the collection segment for a given Type value. Returns the registered override verbatim when one is present (case-insensitive lookup, case-preserving result — an override registered as "People" emits /People/{id}); otherwise returns the naive plural resourceType.ToLowerInvariant() + "s". Callers wanting a lowercase guarantee must lowercase the override at registration time.
