Remarks

Closes the asymmetry where MaybeScalarValueJsonConverterFactory already supports Maybe<TScalar> (typed value objects) but raw Maybe<long> / Maybe<string> / etc. fell through to STJ's default object handling, which silently serializes the Maybe<T> struct's public members (HasValue, HasNoValue, Value) — producing JSON the converter cannot itself parse back. The supported primitive set deliberately mirrors the CompositeValueObjectJsonConverter<T> allowed list (in Trellis.Primitives): the rule is "Maybe<T> works wherever T is a primitive Trellis already supports directly".

Wire shape: JSON null or absent property reads as None; a primitive value reads as From<T>(T?). None writes as JSON null. STJ-native primitive parsing rules apply for the underlying value (formatting errors throw the standard JsonException with a field path).

Registered by AddScalarValueValidation() (or by the convenience helper AddTrellisAspWithScalarValidation()) alongside the existing scalar factory.
