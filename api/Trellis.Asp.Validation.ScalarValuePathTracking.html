Registry of compile-time-closed path-tracking converters, keyed by the container property type they wrap. It is the Native AOT counterpart to the reflection pipeline's runtime Type.MakeGenericType construction: AOT forbids building a closed generic at runtime, so the closed instantiations are created by the source generator at compile time and registered here.

Remarks

Consumers do not normally call this type. The Trellis ASP source generator emits a [ModuleInitializer] that registers every container property type in the DTO graph reachable from a [JsonSerializable]-annotated JsonSerializerContext, so index-precise validation field paths (/members/0/email) work identically in reflection and Native AOT.

Manual registration is supported for the cases the generator cannot see — for example a DTO reached only through a hand-written JsonSerializerContext in another assembly, or a bespoke collection shape. Registration is idempotent and last-call-wins; it is expected to happen once at startup (module initialization), before any deserialization, and is safe to call concurrently.

A property type that is not registered simply falls back to the reflection pipeline (when dynamic code is available) or to leaf-only field names (under AOT) — never to an error.

The value type.

Remarks

Only string-keyed dictionaries are supported: a non-string key has no faithful RFC 6901 rendering, so those shapes fall back to leaf-only paths rather than emitting a pointer a client cannot map back to its input.
