Parameters

In string

The location discriminator — body, query, path, header, or unknown. Always present, never defaulted by omission: an omitted discriminator would force every client to encode the default.

Pointer string

An RFC 6901 JSON Pointer into the request document. Present for body and unknown; absent otherwise.

Name string

The parameter name. Present for query, path and header; absent otherwise.
