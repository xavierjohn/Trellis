Declares that this resource has a single outbound navigation to a related resource of type TRelated identified by TId. Used by the pipeline to walk a chain of resources for indirect (multi-hop) resource authorization.

Remarks

Implement on aggregate roots whose ownership/authorization is evaluated against a different aggregate one or more hops away. Each hop declared on the chain is loaded via the existing SharedResourceLoaderById<TResource, TId> registration for TRelated.

For fan-out (multiple related resources of the same type, e.g. a cricket Match with home and away teams), implement IIdentifyRelatedResources<TRelated, TId> instead.

Paired with IAuthorizeResourceVia<TOwner> on the command. The pipeline resolves a single non-cycling path from the command's leaf resource to its declared owner type at registration time; runtime hops follow that pre-computed path.
