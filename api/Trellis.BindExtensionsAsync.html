Examples

var ct = cancellationToken;
var result = await emailResult
    .Combine(userIdResult)
    .BindAsync((email, userId) => CreateUserAsync(email, userId, ct));

Remarks

These methods handle various async scenarios. Users should capture CancellationToken in their lambda closures when cancellation support is needed.

Both Task and ValueTask variants are provided for performance optimization scenarios.

Remarks

OverloadResolutionPriorityAttribute resolves the historical CS0121 ambiguity against the sibling ValueTask<TResult>-delegate overload on the same sync Result<TValue> receiver when callers pass an inline async lambda whose body returns a synchronous Result<TValue>. Callers who specifically want ValueTask<TResult> still get it via a strongly-typed delegate (the Task overload is not applicable, so priority is not consulted).
