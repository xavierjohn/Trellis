Examples

// Combine 3 validations
var result = EmailAddress.TryCreate(email)
    .Combine(FirstName.TryCreate(firstName))
    .Combine(LastName.TryCreate(lastName))
    .Bind((email, first, last) => User.Create(email, first, last));

// If any fail, all errors are returned
// If all succeed, User.Create is called with all three values

Remarks

These overloads enable combining results to create tuples of 3-9 elements. All results must succeed for the combined result to succeed. If any result fails, all errors are aggregated into a single combined error.

Key characteristics:

  • All validations are executed (no short-circuiting)
  • Error.InvalidInput failures are merged into a single Error.InvalidInput
  • Mixed error types create a composite failure
  • Success returns a tuple containing all values

Use Combine when you need to:

  • Validate multiple independent inputs before processing
  • Collect all validation errors for user feedback
  • Ensure all preconditions are met before proceeding
  • Build complex value objects from multiple simple ones

Examples

var result = EmailAddress.TryCreate(email)
    .Combine(FirstName.TryCreate(firstName))
    .Combine(LastName.TryCreate(lastName))
    .Bind((arg1, arg2, arg3) => ProcessData(arg1, arg2, arg3));

Remarks

This is the primary Combine overload for building up tuples incrementally. Each Combine call adds one more validated value to the tuple. To gate a tuple pipeline on a no-payload validation, pass a Result<Unit>; the Unit becomes the next tuple element (use _ in the destructuring lambda to ignore it).
