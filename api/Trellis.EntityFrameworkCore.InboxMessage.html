A persisted record that a (ConsumerId, MessageId) message has been processed. Its existence is the dedup guarantee: a redelivery of the same message finds the row and is skipped, so a handler's side effects run effectively once.

Remarks

This is transient infrastructure, not a domain aggregate. Rows may be pruned once they are older than the transport's maximum redelivery window — delete sooner and a late redelivery would be reprocessed.
