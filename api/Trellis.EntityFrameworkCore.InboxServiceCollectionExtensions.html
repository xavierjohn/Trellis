AddTrellisInbox<TContext>(IServiceCollection, Action<InboxOptions>)

Registers the inbox dispatcher (IInboxDispatcher) and EF store (Trellis.IInboxStore) for TContext. Pair this with AddTrellisInbox(ModelBuilder) in the context's OnModelCreating, and register the integration-event handlers that should consume the messages (for example via AddIntegrationEventHandler<TEvent, THandler>()).
