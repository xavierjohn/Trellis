AddTrellisOutbox<TContext>(IServiceCollection, Action<OutboxOptions>?)

Registers the outbox relay hosted service for TContext. Pair this with AddTrellisOutbox(ModelBuilder) in the context's OnModelCreating and AddTrellisOutboxInterceptor(DbContextOptionsBuilder) on the options builder. Domain-event handlers and IReportingDomainEventPublisher must also be registered (for example via AddDomainEventDispatch(...)). Host startup validates this publisher and, when integration features are registered, IIntegrationEventPublisher.
