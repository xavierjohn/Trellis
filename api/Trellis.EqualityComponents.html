Remarks

A ref struct sink passed by reference to GetEqualityComponents(ref EqualityComponents). Components are written into a caller-owned inline buffer, so equality, ordering, and hashing traverse a value object's components without allocating. The previous IEnumerable<IComparable?> contract allocated an iterator state machine on every comparison.

Add components in a stable, deterministic order. Derived types that extend a base value object should call base.GetEqualityComponents(ref components) first so the base components keep their positions.
