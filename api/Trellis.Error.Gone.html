For<TResource>(object?, string?, string?)

Convenience factory that builds a Error.Gone for the resource type TResource (its CLR name becomes the resource name).

public static Error.Gone For<TResource>(object? id = null, string? detail = null, string? code = null)

Parameters

id object

Optional identifier of the specific instance.

detail string

Optional human-readable detail.

code string

Optional stable reason code naming why the resource is gone — e.g. "order.purged" versus "order.superseded". Omitted, empty, or whitespace leaves the inherited Unspecified sentinel, so an empty string never reaches the wire. The parameter trails detail because the code is optional here; cases whose code is required (Error.Conflict, Error.InvariantViolation) lead with it.

Error.Gone
