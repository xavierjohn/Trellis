Closed discriminated union of HTTP-transport failures. Each case mirrors a status from the IANA HTTP Status Code Registry (RFC 9110, RFC 6585) and carries header data needed to emit an RFC-compliant response. Flows through Result<TValue> via the envelope Error.TransportFault: new Error.TransportFault(new HttpError.NotAcceptable(...)).

Remarks

Domain code does not construct or pattern-match HttpError. Construction is the responsibility of HTTP-aware boundary code: server-side (Trellis.Asp) and client-side (Trellis.Http).
