Remarks

Map is used when you have a function that always succeeds and you want to transform the value inside a Result without changing its success/failure state. Unlike Bind, Map functions don't return a Result - they return a plain value that gets automatically wrapped in a success Result. If the input Result is a failure, the Map function is skipped and the failure is propagated.

Remarks

Selector contract. func must not return null. Map wraps the returned value in Ok<TValue>(TValue) unconditionally; a null transformation result yields a "successful" Result<TValue> whose Value is null, which subsequent stages will misinterpret. If the transformation can fail or produce no value, project to Maybe<T> first or use Bind with an explicit Result<TValue>-returning selector.
