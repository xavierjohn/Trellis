Class MatchTupleExtensionsAsync

Namespace
Trellis
Assembly
Trellis.Core.dll

Provides asynchronous pattern matching extension methods for Result types containing tuples (2-5 elements). Supports both Task and ValueTask for async pattern matching.

Examples

var ct = cancellationToken;
var response = await GetUserDataAsync(userId)
    .MatchAsync(
        onSuccess: (email, name) => CreateUserAsync(email, name, ct),
        onFailure: error => LogErrorAsync(error, ct)
    );

Remarks

These methods handle various async scenarios with automatic tuple destructuring. Users should capture CancellationToken in their lambda closures when cancellation support is needed.

All variants automatically destructure tuple values for clean, readable async code.
