Remarks

HopLoadResult uses an explicit success flag rather than inferring success from the presence of an error. The default instance is a failure (with a sentinel Error) so a misconfigured hop loader cannot accidentally produce a "successful" result carrying null as the loaded value, which would bypass the empty-list / failed-load short-circuits in ResourceAuthorizationViaBehavior<TMessage, TLeaf, TOwner, TResponse>.
