Remarks

Unlike domain-event dispatch, integration events are not dispatched by a command-pipeline behavior; they are produced via the IIntegrationEventCollector during domain-event handling and published by the transactional outbox relay. These helpers register the default in-process publisher, the scoped collector, and any in-process consumers.

Methods

AddIntegrationEventDispatch(IServiceCollection)

Registers the default IIntegrationEventPublisher (in-process fan-out) and the scoped IIntegrationEventCollector. This is the AOT/trim-friendly entry point; pair it with AddIntegrationEventHandler<TEvent, THandler>(IServiceCollection) for each consumer.

Remarks

Idempotent: calling this more than once registers the publisher and collector exactly once. To deliver integration events to other services, replace the IIntegrationEventPublisher registration with a message-broker adapter after calling this method.
