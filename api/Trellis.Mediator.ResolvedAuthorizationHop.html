toIdType Type

The CLR type of the identifier used to load toType.

extractIds Func<object, IReadOnlyList<object>>

Delegate that, given an instance of fromType, returns the related resource IDs of type toIdType. For singular hops, returns a list of size 0 or 1; for plural hops, returns 0..N IDs.

loadAsync Func<IServiceProvider, object, CancellationToken, Task<HopLoadResult>>

Delegate that loads a single related resource by ID from the request-scoped service provider. Built at registration time so the runtime behavior remains AOT-clean.

isPlural bool

true when this hop is plural (the source declares IIdentifyRelatedResources<TRelated, TId>); false when singular.
