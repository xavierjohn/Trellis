Remarks

The default policy is Propagate — every command returns the original Error.Forbidden / Error.AuthenticationRequired until the consumer opts a resource into HideAsNotFound. There is no global "hide everything" switch by design: hiding existence is a per-resource security decision and a blanket default would silently change the wire shape of every authorization failure.

Translation scope. The pipeline translates only Error.Forbidden and Error.AuthenticationRequired. Other errors (Error.Unexpected, Error.Unavailable, Error.NotFound from the loader, transport faults, …) pass through verbatim — operational signal must not be hidden behind a 404.

Pipeline interaction. When a command implements both IAuthorize and IAuthorizeResource<T>, the static-permission AuthorizationBehavior runs BEFORE the resource-authorization behavior. An unauthenticated caller whose request fails the static gate sees the original 401/403 — the hide-as-NotFound translation never runs. Commands that need existence-hiding to apply to every failure mode should omit IAuthorize and let HideAsNotFound cover the resource-authorization branch alone.

Cache safety. Hidden 404s look identical to real 404s on the wire. Protect them with Cache-Control: no-store or private — a shared cache will otherwise serve an unauthorized actor's synthetic 404 to a later authorized actor.

HideExistence<TAuthorizationResource, TPublicResource>()

Opt the given resource into HideAsNotFound using a separate public resource type for the synthetic NotFound payload. Use this when the loader projects to an internal authorization shape that is not the canonical wire-public type (for example loading OrderOwnership for the authorization check while exposing Order as the public resource).

TAuthorizationResource

The resource type the loader returns (what the pipeline authorizes against).

TPublicResource

The resource type to publish in the synthetic NotFound's ResourceRef. The pipeline also uses this type to locate an IIdentifyResource<TPublicResource, TId> implementation on the message for ID extraction, falling back to IIdentifyResource<TAuthorizationResource, TId> if the public variant is not present.
