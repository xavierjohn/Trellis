Remarks

Generated Required* value objects use this converter so Core-only consumers can serialize and deserialize generated primitives without referencing Trellis.Primitives.

Properties

HandleNull

Tells System.Text.Json to call Read(ref Utf8JsonReader, Type, JsonSerializerOptions) even when the JSON token is null. Without this, the serializer bypasses the converter for null tokens on reference-type targets and yields a null reference, silently violating the non-nullable contract of a generated primitive.
