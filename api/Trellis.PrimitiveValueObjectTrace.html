Remarks

The activity source is named "Trellis.Primitives" because it identifies the brand of concrete primitive value objects (e.g. EmailAddress, Money, CountryCode) that Trellis ships, not the hosting assembly. The version stamped on the source is read from the assembly that physically contains this type — currently Trellis.Core, since Trellis.Primitives only type-forwards PrimitiveValueObjectTrace. This relies on Trellis.Core and Trellis.Primitives shipping in lockstep from the same version.json; if the two packages are ever decoupled in versioning, the stamped version will drift from the Trellis.Primitives NuGet package version that consumers reference.
