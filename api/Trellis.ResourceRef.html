Remarks

The resource type name is the simple CLR name with two normalisations applied:

  1. Backtick mangling stripped. A closed generic such as List<User> reports a CLR Name of "List`1"; the backtick suffix is removed so the resource type is "List". Closed generics with multiple type arguments collapse to the outer simple name (e.g. Dictionary<string,int> → "Dictionary"). When the inner type argument is the meaningful resource identifier, prefer For(string, object?) with an explicit name.
  2. Maybe<T> wrappers are peeled. Maybe<Order> reports "Order", and the peeling is recursive (Maybe<Maybe<Order>> also reports "Order"). This avoids the CLR-mangled "Maybe`1" from leaking onto the wire when a result type happens to wrap its domain in Maybe<T> (e.g. Result<Maybe<Order>>.ToHttpResponse(...)). Other generic wrappers are not peeled — see FormatTypeName(Type) if you need the formatting without the Maybe-peeling step.

FormatTypeName(Type)

Returns the simple CLR name for type with backtick-mangling stripped. Used by Trellis components that surface a type-derived identifier on the wire (e.g. AOT-generated JSON converter fallback messages).

public static string FormatTypeName(Type type)

Parameters

type Type

The type whose name should be formatted.

Returns

string

The simple name with any `N arity suffix removed. For example, typeof(List<int>) returns "List"; typeof(Order) returns "Order".

Remarks

This helper does not peel Maybe<T> wrappers — that is intentionally scoped to For<TResource>(object?), which owns the resource-naming contract.
