AddTrellis(IServiceCollection, Action<TrellisServiceBuilder>)

Applies Trellis integration modules in canonical order.

public static IServiceCollection AddTrellis(this IServiceCollection services, Action<TrellisServiceBuilder> configure)

Parameters

services IServiceCollection

The service collection.

configure Action<TrellisServiceBuilder>

Configures the Trellis service modules to apply.

Returns

IServiceCollection

The same IServiceCollection for chaining.

Examples

services.AddTrellis(options => options
    .UseAsp()
    .UseMediator()
    .UseFluentValidation(typeof(Program).Assembly)
    .UseEntityFrameworkUnitOfWork<AppDbContext>());

Remarks

This method only wires Trellis integration services. Application-owned services such as AddDbContext<TContext>(...) and AddMediator(...) stay explicit.

Exceptions

ArgumentNullException

Thrown when services is null.

ArgumentNullException

Thrown when configure is null.
