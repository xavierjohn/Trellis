Examples

var ct = cancellationToken;
var result = await GetUserDataAsync(userId)
    .TapAsync((email, name) => _logger.LogInformation("User: {Name} ({Email})", name, email))
    .TapAsync((email, name) => SendWelcomeEmailAsync(email, name, ct))
    .BindAsync((email, name) => CreateUserProfileAsync(email, name, ct));

Remarks

These methods handle various async scenarios with automatic tuple destructuring:

  • Async result ? sync action
  • Sync result ? async action
  • Async result ? async action

Both Task and ValueTask variants are provided for performance optimization scenarios. ValueTask is preferred for hot paths where the operation frequently completes synchronously.
