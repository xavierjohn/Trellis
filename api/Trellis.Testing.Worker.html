WorkerHarness<TWorker>

Integration-test harness for a BackgroundService worker. Builds an IHost with a deterministic Microsoft.Extensions.Time.Testing.FakeTimeProvider, a configurable TestActorProvider, and a domain-event capture wired through the Trellis mediator pipeline so tests can advance time, wait for specific events or named tick signals, and assert what the worker emitted.

Interfaces

IWorkerTickSignal

Cooperative signal that a worker tick has completed. The harness registers a singleton implementation; the worker's BackgroundService resolves the interface from DI and calls SignalAsync(CancellationToken) at the end of each tick so the test can block on WaitForTickAsync(TimeSpan?, CancellationToken) instead of Delay(TimeSpan).
