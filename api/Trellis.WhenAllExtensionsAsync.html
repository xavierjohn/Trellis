Provides Await extension methods for waiting on multiple Task-wrapped Result instances and combining them. These methods enable efficient parallel execution of independent async operations with Result aggregation.

Examples

// Execute three independent async operations in parallel
var result = await (
    GetUserAsync(userId),
    GetOrdersAsync(userId),
    GetPreferencesAsync(userId)
).WhenAllAsync();

// All three operations run concurrently
// If all succeed, result contains (user, orders, preferences)
// If any fail, result contains all errors

// Then process the combined result
result.Match(
    onSuccess: (user, orders, prefs) => ProcessData(user, orders, prefs),
    onFailure: error => HandleError(error)
);

Remarks

WhenAllAsync waits for all tasks to complete using Task.WhenAll for efficient parallel execution, then combines their results using the standard Combine semantics.

These overloads expect each task to complete with a Result<TValue>. If a task faults or is canceled, the exception escapes from Task.WhenAll instead of being converted into a failed result.

Key characteristics:

  • All tasks execute in parallel (not sequentially)
  • Waits for all tasks to complete before combining results
  • If any task's result fails, all errors are aggregated
  • Faulted or canceled tasks propagate their exception to the caller
  • More efficient than sequential await chains for independent operations
  • Creates distributed tracing spans for observability

Use WhenAllAsync when you need to:

  • Execute multiple independent async operations in parallel
  • Wait for all operations to complete before proceeding
  • Combine results from parallel operations
  • Maximize throughput for I/O-bound operations
  • Monitor parallel operation performance in distributed traces

Awaits two parallel async Result operations and combines their results.

public static Task<Result<(T1, T2)>> WhenAllAsync<T1, T2>(this (Task<Result<T1>>, Task<Result<T2>>) tasks)

Parameters

tasks (Task<Result<T1>>, Task<Result<T2>>)

A tuple containing two tasks that produce Result values.

Returns

Task<Result<(T1, T2)>>

A task that represents the asynchronous operation. The task result contains:

  • A success result with a 2-element tuple if both tasks succeed
  • A failure result with combined errors if either task fails

Examples

var result = await (
    GetUserAsync(userId),
    GetOrdersAsync(userId)
).WhenAllAsync();

result.Match(
    onSuccess: (user, orders) => ProcessUser(user, orders),
    onFailure: error => LogError(error)
);

Remarks

This method uses Task.WhenAll to execute both operations in parallel, then combines their results using standard Combine semantics. If either task faults or is canceled, that exception escapes immediately. Creates a distributed tracing span to monitor parallel execution.

var r1 = await Task1(); // Wait
var r2 = await Task2(); // Wait
var r3 = await Task3(); // Wait sequentially
