Class WriteOutcome

Namespace
Trellis
Assembly
Trellis.Http.Abstractions.dll

Factory helpers that build a WriteOutcome<T> case but return the base type, so call sites flow through generic pipelines (for example Result.Map / ToHttpResponse) without an explicit (WriteOutcome<T>) cast to widen the nested case. Mirrors the non-generic Result / generic Result<T> pairing.
